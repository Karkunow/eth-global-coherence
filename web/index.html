The three propositions

A = WETH/USDC ends higher in 24h
B = USDC/WBTC ends higher in 24h
C = WBTC/WETH ends higher in 24h

The agent is asked about them in three separate, isolated calls, e.g. context (A,B) is only asked about A and B, blind to the third proposition. This forms partial probability distributions.

After that we're using an expectation value for a full (A,B,C) distribution, which should equal exactly 2.0 ideally, as a measure of the coherence of the model the agent is using.
